# Card Genre Template

## Genre Characteristics

- Card collection as core
- Turn-based/Real-time combat
- Strong strategy, team composition
- Gacha-driven, character progression

## Progression System List

### Core Progression

| Progression System | Description | Associated Gift Pack Types |
|--------------------|-------------|----------------------------|
| Hero Card | Core combat unit | Hero fragments, Hero upgrade, Hero summon vouchers |
| Star Breakthrough/Star Upgrade | Card star upgrade | Star materials, Star upgrade stones, Breakthrough stones |
| Equipment/Artifact | Extra attributes | Equipment upgrade, Sets, Artifact fragments |
| Skill Upgrade | Skill enhancement | Skill books, Skill points, Skill materials |

### Advanced Progression

| Progression System | Description | Associated Gift Pack Types |
|--------------------|-------------|----------------------------|
| Bond/Destiny | Combination bonus | Bond activation, Destiny materials |
| Awakening/Constellation | Character awakening | Awakening materials, Constellation fragments, Stars |
| Exclusive Weapon | Character exclusive | Exclusive weapon fragments, Exclusive weapon upgrade materials |
| Talent/Rune | Attribute boost | Talent points, Rune fragments |
| Holy Relic/Relic | Random attributes | Holy relics, Enhancement materials |
| Affection/Intimacy | Character interaction | Affection items, Gifts |

### Progression Resources

| Progression System | Description | Associated Gift Pack Types |
|--------------------|-------------|----------------------------|
| Experience/Level | Basic growth | Experience potions, Experience cards |
| Gold/Gems | Universal currency | Gold, Gems, Tokens |
| Stamina/Energy | Challenge consumption | Stamina potions, Energy potions |
| Gacha Resources | Summon resources | Summon vouchers, Gems, Gacha tokens |

## Gameplay Classification

### PVE Gameplay

| Gameplay | Description | Output/Associated Gift Pack | Trigger Scenario |
|----------|-------------|------------------------------|------------------|
| Adventure/Main | Story stages | Hero fragments, Experience potions, Equipment materials | Stage failure, Chapter completion, Stage stuck |
| Elite Stage | Resource acquisition | Hero fragments, Equipment fragments, Rare materials | Challenge failure, Three-star failure |
| Tower/Trial | Extreme challenge | Tower coins, Rare materials, Hero fragments | Floor stuck, Challenge failure |
| Event Dungeon | Limited-time challenge | Event tokens, Limited items, Hero fragments | Event participation, Full rewards claimed, Time shortage |
| Endless Challenge | Wave challenge | Endless coins, Equipment materials, Hero fragments | Wave failure, Challenge ended |
| Expedition/Explore | Auto explore | Expedition resources, Hero fragments, Gold | Expedition failure, Exploration complete |

### PVP Gameplay

| Gameplay | Description | Output/Associated Gift Pack | Trigger Scenario |
|----------|-------------|------------------------------|------------------|
| Arena | Ranking battle | Arena coins, Honor points, Hero fragments | Rank drop, Challenge failure, Win streak broken |
| Guild War | Team competition | Guild contribution, Guild coins, Rare materials | Battle failure, Personal contribution low |
| Tournament | Elimination format | Tournament coins, Rare materials, Titles | Eliminated, Promotion success |
| Cross-server Arena | Server competition | Cross-server coins, Rare materials, Hero fragments | Battle failure, Rank drop |
| Real-time Battle | Instant match | Arena coins, Honor points, Hero fragments | Battle failure, Tier drop |

### Social/Guild Gameplay

| Gameplay | Description | Output/Associated Gift Pack | Trigger Scenario |
|----------|-------------|------------------------------|------------------|
| Guild Boss | Collective challenge | Guild contribution, Hero fragments, Rare materials | Low damage ranking, Boss kill |
| Guild Task | Daily task | Guild contribution, Guild coins, Experience potions | Task not completed, Contribution insufficient |
| Friend Assist | Assist gameplay | Assist rewards, Friendship points, Gold | Assist success, Assist reward |
| Guild Shop | Exchange items | Guild coins exchange items | Points insufficient, Item refresh |

### Limited-time/Event Gameplay

| Gameplay | Description | Output/Associated Gift Pack | Trigger Scenario |
|----------|-------------|------------------------------|------------------|
| Limited-time Event | Holiday event | Event tokens, Limited heroes, Rare materials | Event start, Rewards not claimed |
| Element Tower/Attribute Tower | Attribute restriction | Element materials, Hero fragments, Equipment materials | Challenge failure, Floor stuck |
| Secret Realm/Dungeon | Random explore | Secret realm materials, Holy relics, Gold | Exploration failure, Chest open |
| Arena Season | Season gameplay | Season rewards, Tier protection cards, Titles | Season settlement, Tier up/down |
