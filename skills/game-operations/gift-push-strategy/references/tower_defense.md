# Tower Defense Genre Template

## Genre Characteristics

- Strategic layout as core
- Tower/Unit progression
- Stage challenge, Wave defense
- Tower Defense + RPG fusion trend

## Progression System List

### Core Progression

| Progression System | Description | Associated Gift Pack Types |
|--------------------|-------------|----------------------------|
| Defense Tower | Core defense unit | Tower upgrade, Tower advancement, Tower fragments, Tower unlock vouchers |
| Hero/Commander | Special unit | Hero unlock, Hero upgrade, Hero fragments, Hero equipment |
| Tech/Talent | Global bonus | Tech upgrade, Talent points, Tech materials |
| Level/Experience | Basic growth | Experience potions, Double experience cards |

### Advanced Progression

| Progression System | Description | Associated Gift Pack Types |
|--------------------|-------------|----------------------------|
| Skin/Appearance | Display progression | Tower skins, Effects, Skin vouchers |
| Rune/Gem | Attribute bonus | Runes, Gems, Socket materials |
| Artifact/Holy Relic | Special equipment | Artifact fragments, Artifact upgrade materials |
| Trap/Item | Auxiliary defense | Traps, Items, Consumables |
| Album/Collection | Collection system | Album fragments, Collection rewards |
| Achievement/Medal | Achievement system | Medals, Achievement rewards |

### Resource System

| Progression System | Description | Associated Gift Pack Types |
|--------------------|-------------|----------------------------|
| Gold/Gems | Universal currency | Gold, Gems, Tokens |
| Stamina/Energy | Challenge consumption | Stamina potions, Energy potions |

## Gameplay Classification

### Stage Gameplay

| Gameplay | Description | Output/Associated Gift Pack | Trigger Scenario |
|----------|-------------|------------------------------|------------------|
| Main Stage | Story progression | Tower fragments, Hero fragments, Gold | Stage failure, Wave defense failure, Stage three-star |
| Elite Stage | High difficulty stage | Elite materials, Tower advancement materials, Rare tower fragments | Challenge failure, Three-star failure |
| Infinite Mode/Endless | Extreme challenge | Endless coins, Rare materials, Tower fragments | Wave stuck, Failure, Record breakthrough |
| Challenge Stage | Special challenge | Challenge coins, Rare materials, Hero fragments | Challenge failure, Challenge success |
| Boss Stage | Boss challenge | Boss coins, Artifact fragments, Rare tower fragments | Boss kill failure, Boss kill success |

| Gameplay | Description | Output/Associated Gift Pack | Trigger Scenario |

| Guild War/Alliance War | Team competition | Guild contribution, Guild coins, Rare materials | Battle failure, Contribution insufficient |
