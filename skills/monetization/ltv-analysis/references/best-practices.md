# LTV Internal Best Practices Reference

## LTV Improvement Core Formula

```
LTV↑ = Data Loop Construction + User Lifecycle Management + Product Experience Optimization + Monetization Efficiency Improvement
```

| Dimension | Core Points | Key Actions |
|----------|-----------|-------------|
| Data Loop Construction | Full-domain data collection, data insight system, automated decision-making | Connect multi-terminal data, build metric system, strategy rule engine |
| User Lifecycle Management | Scientific segmentation, phased outreach, user-level early warning | Dynamic user segmentation, behavior triggers, private channel outreach |
| Product Experience Optimization | Data-driven iteration, A/B experiments, heatmap analysis | Config center hot updates, gameplay data feedback, user path optimization |
| Monetization Efficiency Improvement | Dynamic user segmentation, real-time behavior judgment, personalized outreach | Payment demand capture, multi-channel outreach, data asset reuse |

## User Segmentation Strategy

| Tier | Division Standard | Payment Characteristics | Operations Strategy |
|------|-----------------|----------------------|-------------------|
| Low Spender | <$5 per transaction | Price sensitive, heavily impacted by pricing | Micro-payment points/limited-time discounts |
| Mid Spender | $5-$50 per transaction | Value-driven, impacted by promotions | Value bundles/monthly activities |
| High Spender | >$50 per transaction | Status-driven, impacted by service | Exclusive activities/one-on-one service |

## LTV Early Prediction Indicators (First 7 Days)

| Indicator | Weight | Description |
|----------|--------|-------------|
| Active Days | High | More active days in first 7 days = higher LTV |
| Task Completion Rate | High | High task completion = high engagement |
| Alliance Participation | High | Alliance participation is an important LTV predictor |
| First Purchase Conversion | Medium | First purchase users have significantly higher LTV than non-payers |
| Core Gameplay Participation | Medium | PVP participation, building upgrades and other core behaviors |

**Evaluation Time Windows**: D1 (quick filter) → D7 (mainstream evaluation) → D14 (precise evaluation) → D30 (final confirmation)

## Price Anchoring Principles

| Tier | Value Range | Price Interval Principle | Goal |
|------|-----------|------------------------|------|
| Low tier | 3-5x | Interval with mid tier ≥2x | Low Spender penetration, payment ice-breaking |
| Mid tier | 2.5-4x | Interval with low/high tier 1.5-2x | Mid Spender main, revenue stability |
| High tier | 2-3x | Interval with mid tier ≥1.5x | High Spender exclusive, ARPPU improvement |

**Note**: Value = Item value / price, higher value = better user perception of value
