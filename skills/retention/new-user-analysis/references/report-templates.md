# Report Templates

> **Purpose**: Output templates for all 4 phases of new-user-analysis.
> **Format Strategy**: Phase 1/2 = structured Markdown (lightweight, copy-paste friendly). Phase 3/4 = self-contained HTML with Chart.js (visualization-heavy).
> **Output Directory**: All reports saved to `outputs/` in workspace.

---

## Phase 1 — Caliber Confirmation Report (Markdown)

### Template: `phase1-caliber-confirmation.md`

```markdown

**Generated**: {generation_date}

---

|-------|-------|

---

## 2. Data Quality Notes

{data_quality_notes}

| Check | Result |
```
